# Python async/await 入门课程设计

## 目标

在 `Python基础/代码` 下新增第 24 课，帮助已经学完函数、模块、面向对象和文件操作的初学者理解 Python 异步编程的基本用法。

课程完成后，学习者应能：

- 说明协程与普通函数的主要区别。
- 使用 `async def` 定义协程。
- 使用 `await` 等待异步操作。
- 使用 `asyncio.run()` 启动异步程序。
- 使用 `asyncio.create_task()` 并发调度任务。
- 使用 `asyncio.gather()` 收集多个任务的结果。

## 目录与文件

新建目录：

`Python基础/代码/24-python异步编程async-await/`

目录内包含五个可独立运行的示例：

1. `1.为什么需要异步.py`：通过串行等待介绍异步编程适合处理等待时间较多的任务。
2. `2.协程和asyncio.run.py`：介绍 `async def`、协程对象与 `asyncio.run()`。
3. `3.await等待异步操作.py`：演示协程之间通过 `await` 顺序协作。
4. `4.create_task并发执行.py`：对比顺序等待与并发任务的耗时。
5. `5.gather收集任务结果.py`：并发执行多个协程并汇总返回值。

## 内容约束

- 只使用 Python 标准库 `asyncio` 和 `time`，不依赖网络与第三方软件包。
- 使用短暂的 `asyncio.sleep()` 模拟文件下载、接口请求等 I/O 等待，确保结果稳定且运行快速。
- 示例由浅入深，每个文件聚焦一个核心知识点。
- 每个 Python 有效代码行前添加准确、简短的中文独立行注释，遵守仓库 `AGENTS.md` 的要求。
- 示例使用 `if __name__ == "__main__":` 作为运行入口，避免导入时自动执行。

## 错误与边界说明

- 明确说明直接调用异步函数只会得到协程对象，不会立即执行函数体。
- 明确说明 `await` 只能在异步函数内部使用。
- 明确说明异步并不等于多线程，适合以 I/O 等待为主的任务。
- 所有创建的任务都会被等待完成，避免退出时遗留未完成任务。

## 验证方式

- 使用当前 Python 解释器逐个执行五个示例，确认退出码均为 0。
- 检查所有 Python 有效代码行前均有中文独立行注释。
- 检查 `create_task` 和 `gather` 示例的输出包含预期结果，并体现并发执行。
