# LangChain 流式输出示例包设计

## 目标

在 `langchain-learn/` 中新增 `streaming/` Python 包，演示 OpenAI 兼容聊天模型的流式文本输出，以及 LangChain 回调事件的实时观察。

## 包结构

- `streaming/__init__.py`：标识 Python 包，并导出面向学习者的演示入口。
- `streaming/app.py`：复用现有环境变量约定，创建配置了回调处理器的 `ChatOpenAI` 模型，并提供逐块读取文本的函数。
- `streaming/callbacks.py`：定义终端回调处理器，分别输出模型开始、增量 token、模型结束和错误事件。
- `streaming/main.py`：调用流式函数，将每一个模型文本分块立即输出到终端。
- `tests/test_streaming.py`：使用替身模型与捕获输出，不联网验证文本分块处理和回调输出。

## 数据流

入口创建回调处理器后，从既有 `app.py` 获取已校验的 `Settings`。随后将配置应用于 `ChatOpenAI`，并调用模型的 `stream()`。每个返回的 `AIMessageChunk` 会被转换为非空文本后立刻打印；回调处理器同步展示生命周期事件。缺少密钥时复用既有 `ConfigurationError`，模型或网络异常由入口打印简洁信息并返回非零状态码。

## 输出约定

终端会先显示回调事件，再连续显示模型生成的文本，最后显示结束事件。回调信息使用固定、易读的中文前缀，避免混入或重复模型正文。空文本分块不输出，保证流式正文连贯。

## 依赖与范围

继续使用已有的 `langchain-openai`、`python-dotenv` 和 `pytest`，不增加第三方依赖。示例只包含终端流式输出和回调事件，不引入 Web UI、Agent、工具调用、记忆或新的模型供应商。

## 验证

测试不访问网络或真实密钥。测试将验证：非空文本分块按顺序产出；空内容被忽略；回调处理器输出开始、token、结束及错误信息；入口在配置异常时返回失败状态。README 将增加流式包的运行命令与行为说明。

## 仓库约束

所有新增或修改的 Python 有效代码行之前均添加准确、简短的中文独立行注释。
